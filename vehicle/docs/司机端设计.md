# 司机端（司机 App）设计文档

## 一、项目简介

司机端为车辆调度平台的移动端配套应用，供内部司机与外部车队司机使用，主要能力包括：接收派车任务、执行行程、上报定位轨迹、提交费用账单、接收消息通知等。司机端与 PC 端（车辆管理系统）共享同一套订单、轨迹、账单数据，司机在 App 端的操作与 PC 端订单状态流转实时联动。

## 二、角色与登录

### 1. 司机账号

- 司机档案由 PC 端"系统管理 - 司机管理"维护：头像、姓名、性别、工号、电话、短号、准驾车型、办公地点、评分（星级）、内部/外部身份。
- 内部司机与外部司机（外部车队）身份区分，外部司机相关业务由外部管理员在 PC 端管理（外部订单、司机、车辆）。

### 2. 车辆绑定

- 司机与车辆存在绑定关系，车辆档案包含：车牌号、品牌型号、颜色、绑定司机、座位数、车辆类型、定位器 ID、内部/外部。
- 司机登录后自动加载其绑定车辆信息（车牌号、定位器 ID），作为轨迹上报与账单关联的归属依据。

### 3. 登录方式

- 工号 + 密码登录（与 PC 端同一账号体系），支持 SSO 集成。
- 登录后拉取司机档案、绑定车辆、待办任务与未读消息。

## 三、任务接单

### 1. 任务列表

- **待出发**：已被分配但尚未开始的订单；**进行中**：当前执行的订单；**已完成**：历史订单。
- 订单卡片展示：起点/终点、出发时间、乘车人（姓名/电话/短号）、乘车人数、其他要求（如接机需查看航班号）。

### 2. 接单与拒单

- 司机可接单或拒单，被拒订单回到 PC 端"订单列表"，由管理员重新分配（指派其他车辆与司机）。
- 接单后订单状态流转为"待出发"，司机可查看订单详情（含拼车详情）。

### 3. 状态联动

司机端操作与 PC 端订单状态流转同步：

待处理 → 待分配 → **待出发 → 接人途中 → 等乘客 → 行驶中 → 待评价** → 已完成

另有已取消、已删除状态（司机端对应订单从任务列表移除）。

## 四、行程执行

### 1. 行程打点

- **开始行程**：司机到达出发地接人后点击，状态由"待出发"流转为"接人途中"，同时作为轨迹段的起始锚点上报。
- **到达接人**：状态流转为"等乘客"。
- **行程开始**：乘客上车出发，状态流转为"行驶中"，进入高频轨迹上报模式。
- **到达目的地**：行程结束，状态流转为"待评价"，上报轨迹段结束锚点并停止定位。

### 2. 导航集成

- 集成百度地图导航，一键导航至出发地/目的地，司机端地图与 PC 端"地图模式"共用百度地图能力。

### 3. 拼车

- 拼车订单展示拼车详情（同车多订单），司机按拼车顺序依次接送。

## 五、车辆轨迹（核心能力）

### 1. 定位数据采集

**定位源**：App 内置 GPS 定位为主，基站/WiFi 辅助定位兜底（室内、隧道场景）。

**上报策略**（平衡实时性与耗电）：

| 场景 | 频率 | 说明 |
| --- | --- | --- |
| 订单行驶中（前台） | 每 3~10 秒 | 高频上报，保证轨迹连续 |
| 静止/怠速 | 30~60 秒 | 位移无变化时降频，省电省流量 |
| 后台运行 | 1~5 分钟 | 低功耗定位，仅保底 |
| 订单结束/到达 | 立即上报 | 打轨迹断点，关闭定位 |

**触发式上报**：位移超过阈值（如 50 米）或方向大幅变化时额外上报一点，避免直线段中间冗余点。

**上报内容**：定位器 ID（司机手机对应"司机"类型，车载硬件对应"车辆"类型）、经纬度、海拔、速度、方向角、时间戳、关联订单号。

### 2. 轨迹存储（服务端）

- **轨迹点表**：定位器 ID + 订单 ID + 经纬度 + 海拔 + 速度 + 方向 + 时间，按定位器 ID + 时间建索引。
- **抽稀存储**：入库前用道格拉斯-普克（Douglas-Peucker）算法抽稀，直线段只留首尾点，减少存储与前端绘制压力。
- **轨迹分段**：按订单行程分段存储，支持"一次行程一条轨迹"的查询维度（PC 端"车辆轨迹"页按定位器 + 时间段查询同一份数据）。
- **数据保留**：热数据保留数月，过期归档到离线存储。

### 3. 实时轨迹展示

- 接单后地图显示本订单行驶路线，实时更新当前位置标记，顶部展示已行驶里程/时长。
- 行驶轨迹以百度地图 Polyline 折线绘制，按速度或轨迹密度着色（与 PC 端"车辆轨迹"页渲染方案一致）。

### 4. 历史轨迹回放

- 入口：我的行程 → 行程详情 → 轨迹回放。
- 展示某次订单的完整轨迹、起终点、里程、时长。
- 按时间轴模拟小车沿折线移动，支持倍速播放（1x/2x/4x）、暂停、拖拽进度条。

### 5. 轨迹纠偏与异常处理

- **漂移过滤**：速度超阈值、点间距离突变的点剔除，避免轨迹穿楼、跨河。
- **离线补传**：断网时轨迹点缓存在本地，恢复网络后按时间顺序补传，防止轨迹断裂。
- **信号中断**：长时间无信号时，轨迹段标注"信号中断"区间，回放时提示。
- **换车/换绑**：按定位器 ID 区分数据归属，司机换绑车辆后轨迹自动归属新绑定关系。

### 6. 与 PC 端联动

- PC 端"位置"页展示司机端定位器实时位置（类型：司机/车辆），支持圈选半径查询。
- PC 端"车辆轨迹"页按定位器 + 时间段查询行驶轨迹，与司机端共享数据源。
- 轨迹数据可作为账单/补贴审核依据（里程与订单不符、轨迹缺失段核查）。

## 六、账单与补贴

### 1. 账单类型

司机在行程中产生的费用账单：行程补贴、饭补、跟车补贴、油费、过路费、停车费等。

### 2. 提交与审批

- 司机在 App 端提交账单（类型 + 金额 + 备注），接入 BPM 审批流程。
- 审批通过后入账；被驳回的账单回到司机端可修改重新提交，也可由 PC 端"驳回补贴"页面处理（管理员查看账单明细、修改金额后重新提交 BPM 审批）。
- PC 端"数据统计 - 账单管理"维护司机账单记录（司机、工号、车牌、车型、账单类型、金额、账单时间），司机端账单数据与其同源。

## 七、评价

- 订单完成（待评价）后，乘客对司机进行评价：星级评分 + 评价标签。
- 评价标签由 PC 端"数据字典"维护（评价标签及标签提示）。
- 司机评分（星级）沉淀到司机档案，在司机端个人中心展示。

## 八、消息通知

- 订单相关通知：新任务分配、行程变更、取消提醒。
- 公告消息：PC 端"消息管理 - 公告"发布的公告可推送至司机端，司机参与回执（已回执/未回执统计）。
- 接收提醒开关：账号可配置"是否接收提醒"（PC 端 Web 用户字段）。

## 九、个人中心

- 个人信息：姓名、工号、性别、电话、短号、办公地点、准驾车型。
- 绑定车辆：车牌号、车辆类型、定位器 ID。
- 评分展示：星级评分与近期评价标签。
- 我的账单：账单记录与审批状态（待审批/通过/驳回）。

## 十、与 PC 端联动关系

| 能力 | 司机端 | PC 端 |
| --- | --- | --- |
| 订单 | 任务接单、行程执行、状态上报 | 订单列表、分配/重新分配/转派、派车补单 |
| 轨迹 | 定位上报、实时轨迹、历史回放 | 位置页、车辆轨迹页（查询/回放） |
| 账单 | 提交账单、重新提交 | 账单管理、驳回补贴处理 |
| 档案 | 查看个人信息与绑定车辆 | 司机管理、车辆管理 |
| 评价 | 接收乘客评价 | 数据字典维护评价标签 |
| 消息 | 订单通知、公告回执 | 公告发布与回执统计 |
