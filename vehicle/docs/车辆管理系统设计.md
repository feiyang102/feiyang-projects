# 车辆管理系统（vehicle-web）设计文档

## 一、项目简介

车辆调度管理平台，核心业务为派车申请与车辆调度，配套提供消息通知等行政服务。系统为 PC 端中后台管理平台，配套 App/移动端使用，支持中英文双语界面。

## 二、角色与权限

- **超级管理员**：拥有全部模块与操作权限
- **管理员**：车辆订单、系统管理、消息、数据统计等核心模块
- **外部管理员**：外部车队相关业务（外部订单、司机、车辆）

菜单与操作按钮均按角色动态显示。

## 三、核心模块：车辆管理

### 1. 内部订单

- 列表查询：关键词、订单状态多选、出发日期区间、拼车模式筛选
- 订单操作：分配（指派车辆与司机）、重新分配、转派外部车队、编辑、删除
- 路线与详情：点击起终点查看地图路线，双击行或点击详情查看订单详情（含拼车详情）
- 其他：导出 Excel、发起派车补单

### 2. 订单详情

展示发起人、乘车人（工号/姓名）、用车原因、单据号、出发/到达地点与时间、订单状态等字段，支持导出。

### 3. 外部订单

外部车队承接的订单列表，额外展示用车公司（公爵、琦昌等），支持退回、删除、编辑。

### 4. 派车补单

派车补单表单，包含：

- 基本信息：发起人（按工号/姓名查询）、出发地/目的地（省市区选择 + 详细地址）、出发时间、预计到达时间、乘车人数、联系人工号/姓名/电话/短号、其他需求（如接机需填写航班号）、财务审批人
- 司机信息：可添加多名司机，逐条绑定司机（工号/姓名/电话）与车牌号
- 评价：星级评分 + 评价标签

### 5. 地图模式

- 百度地图展示订单出发/到达点标记（带编号）
- 支持圈选半径、时间段筛选、标记显示/隐藏
- 支持勾选多个订单进行拼车分配

### 6. 位置

地图与列表结合的实时定位页面：

- 左侧为百度地图，展示定位器实时位置标记；右侧为定位列表，可点击箭头展开/收起
- 支持车辆、司机定位，定位类型包括：用户/司机/车辆
- 支持关键字搜索（工号或车牌），搜索结果展示在页面右侧的列表中
- 地图左上角支持切换城市，并带有圈选半径输入框（以米为单位，支持手动输入，默认 2000 米）
- 点击列表某一行，以该坐标点为圆心按半径画圆，查询圈内定位；支持圈选半径，查询地图范围内定位
- 列表字段：工号或车牌号（定位器 ID）、类型（用户/司机/车辆）、经度、纬度、海拔、更新时间；点击列表项可在地图上定位到对应标记

### 7. 轨迹

地图左上角工具栏依次提供筛选控件：

- 城市筛选：地图左上角，支持切换城市
- 定位器类型下拉：APP 用户 / 司机 / 车辆
- 定位器搜索框：选择下拉类型后，右侧输入框支持关键字搜索（工号或定位器 ID），输入时有备选项（联想）
- 开始时间、结束时间：日期时间选择器
- 搜索按钮：按所选定位器 + 时间段查询行驶轨迹，地图以折线按轨迹密度着色展示

### 8. 账单拒绝

被司机拒绝的账单列表，可查看账单明细（类型/金额/备注）并修改金额。

### 9. 订单状态流转

待处理 → 待分配 → 待出发 → 接人途中 → 等乘客 → 行驶中 → 待评价 → 已完成；另有已取消、已删除状态。

## 四、菜单结构总览

车辆管理平台左侧菜单共 6 个一级菜单：**公务车、系统管理、消息管理、数据统计、工作台、关于**（按摩预定、私家车管理、资产盘点、个税专项扣除、生日祝福为独立业务系统，不属于本设计范围）。以下说明本平台核心菜单的层级、包含关系、页面、功能、字段与交互：

**公务车（一级菜单，/vehicle）**——车辆管理模块入口，登录后默认进入"订单列表"，按角色显示可见菜单

- **订单列表**（/vehicle/order）：派车订单查询与管理入口（关键词、状态、日期、拼车模式筛选；分配、重新分配、转派外部、编辑、删除、路线查看、导出），所有车辆管理角色可见
- **订单明细**（/vehicle/orderDetails）：订单全字段明细查询（发起人、乘车人、用车原因、单据号、起止地点时间等），支持导出
- **外部订单**（/vehicle/externalOrder）：外部车队承接订单管理（退回、删除、编辑），仅管理员/超级管理员可见
- **派车补单**（/vehicle/orderApplication）：补录派车订单的表单入口（发起人、起终点、时间、乘车人、财务审批人、多司机绑定、评价），仅管理员/超级管理员可见
- **地图模式**（/vehicle/mapMode）：地图化订单管理（起终点标记、圈选、拼车分配）
- **位置**（/vehicle/location）：用户/司机/车辆定位器实时位置，仅管理员/超级管理员可见
- **车辆轨迹**（/vehicle/trajectory）：按定位器+时间段查询行驶轨迹，仅管理员/超级管理员可见
- **驳回补贴**（/vehicle/billRefused）：处理被驳回的司机账单的列表页。司机产生的行程补贴、饭补、跟车补贴、油费、过路费、停车费等账单提交审批被驳回后在此处理：查看账单明细（类型/金额/备注）、修改金额后重新提交 BPM 审批，仅管理员/超级管理员可见
  - 列表字段：序号、乘车人、起点、终点、账单备注、出发时间、乘车人数、拼车（详情/拼车详情）、订单状态、车辆（车牌号）、司机、操作（修改金额）
- **订单详情**（/vehicle/viewOrder）：隐藏页，不在菜单显示，在"订单列表"中通过双击行或点击详情/拼车详情进入

**系统管理（一级菜单，/systemManagement）**——超级管理员/管理员/外部管理员可见

- **数据字典**（/systemManagement/dataDictionary）：维护系统字典项（名称+值+类型），类型包括司机分组、维修类型、车牌前缀、车辆类型、准驾车型、地区、保险公司、评价标签及标签提示等，支持新增/编辑/删除
- **Web 用户**（/systemManagement/vehUser）：PC 端账号管理，仅超级管理员/管理员可操作。列表：工号、姓名（点击查看用户信息）、电话、短号、角色、创建时间、操作（编辑/删除），支持勾选批量删除；筛选：关键词（工号/姓名）+ 按角色；新增/编辑表单：工号（回车自动带出 vChat 信息：姓名/性别/电话/短号/头像）、姓名、性别、角色（单选：管理员、外部管理员、正骨按摩管理员、盘点管理员、个税扣除管理员、生日祝福管理员、私家车管理员、测试组派车、测试组查看）、办公地区（单选：全部区域、东莞、重庆、南京）、密码、电话、短号、头像、是否接收提醒
- **司机管理**（/systemManagement/driver）：司机档案管理，列表字段：头像、姓名、性别、工号、电话、短号、准驾车型、办公地点、评分（星级）、内部/外部身份，支持新增/编辑/删除/查看
- **车辆管理**（/systemManagement/vehicle）：车辆档案管理，列表字段：车牌号、品牌型号、颜色、绑定司机、座位数、车辆类型、定位器 ID、内部/外部，支持新增/编辑/删除/查看

**消息管理（一级菜单，/messageManagement）**——超级管理员/管理员可见

- **公告**（/messageManagement/message）：公告发布与回执管理。列表字段：标题、内容（可含图片附件）、回执统计（已回执/未回执人数）、接收对象、创建人与时间；操作：创建、编辑、发布、删除；点击查看回执明细（已回执人员：回执人/时间/备注；未回执人员列表）

**数据统计（一级菜单，/dataStatistics）**——超级管理员/管理员可见

- **账单管理**（/dataStatistics/bill）：司机账单记录（司机、工号、车牌、车型、账单类型（行程补贴/饭补/跟车补贴等）、金额、账单时间），支持新增/编辑/删除/查看
- **车辆维修**（/dataStatistics/repair）：车辆维修记录（司机、车牌、维修类型、维修时间、维修描述），支持新增/编辑/删除/查看
- **车辆账单**（/dataStatistics/vehicleBill）：按车辆维度统计订单里程与行驶时长
- **司机用车统计**（/dataStatistics/driverStats）：按司机维度统计订单数、订单里程、行驶时长及维修费/补贴/餐补等费用，可下钻查看该司机的订单明细
- **员工用车统计**（/dataStatistics/userStats）：按用户维度统计订单数、取消数、行程数、订单里程、行驶时长

**工作台（一级菜单，/workbench）**

- **个人中心**（/workbench/userCenter）：查看个人信息（姓名、工号、性别、电话），支持修改密码、更换头像
- **查看上传文件**（/workbench/viewUploadFile，仅超级管理员）：上传文件记录（来源 PC/Android、文件名、上传人工号/姓名、标签、上传时间、下载链接），支持在线下载

**关于（一级菜单，/about）**

- **关于**（/about/about）：系统使用帮助（FAQ）页面，以折叠面板展示：标签页操作（右键关闭当前/其他/所有、滚轮切换）、表格显示（折叠菜单、右键表头隐藏列、拖拽调整列宽）、数据刷新（右上角刷新按钮）、头像（查看个人信息、更换头像）

各菜单对应功能详见"三、核心模块：车辆管理"及以下各章节。

## 五、系统管理

### 1. 数据字典

维护系统字典项（名称 + 值 + 类型），类型包括：司机分组、维修类型、车牌前缀、车辆类型、准驾车型、地区、保险公司、评价标签及标签提示等。

### 2. Web 用户

PC 端（Web）账号管理，管理可登录本系统的用户账号：

- 列表筛选：关键词（工号/姓名）、按角色筛选；列表字段：工号、姓名（可点击查看用户信息）、电话、短号、角色、创建时间、操作（编辑/删除），支持勾选批量删除
- 新增/编辑表单：工号（输入后回车自动带出 vChat 用户信息：姓名、性别、电话、短号、头像）、姓名、性别、角色（单选：管理员、外部管理员、正骨按摩管理员、盘点管理员、个税扣除管理员、生日祝福管理员、私家车管理员、测试组派车、测试组查看）、办公地区（单选：全部区域、东莞、重庆、南京）、密码、电话、短号、头像、是否接收提醒
- 新增/编辑/删除仅超级管理员/管理员可操作

### 3. 司机管理

司机档案：头像、姓名、性别、工号、电话、短号、准驾车型、办公地点、评分（星级）、内部/外部身份，支持新增/编辑/删除。

### 4. 车辆管理

车辆档案：车牌号、品牌型号、颜色、绑定司机、座位数、车辆类型、定位器 ID、内部/外部，支持新增/编辑/删除。

## 六、消息管理

- 消息列表：标题、内容（可含图片附件）、回执统计（已回执/未回执人数）、接收对象、创建人与时间
- 操作：创建、编辑、发布、删除
- 回执明细：查看已回执人员（回执人/时间/备注）与未回执人员列表

## 七、数据统计

### 1. 账单

司机账单记录：司机、工号、车牌、车型、账单类型（补贴/餐补/跟车费等）、金额、账单时间，支持新增/编辑/删除/查看。

### 2. 维修

车辆维修记录：司机、车牌、维修类型、维修时间、维修描述，支持新增/编辑/删除/查看。

### 3. 车辆统计

按车辆维度统计订单里程与行驶时长。

### 4. 司机统计

按司机维度统计订单数、订单里程、行驶时长及维修费/补贴/餐补等费用，可下钻查看该司机的订单明细。

### 5. 用户统计

按用户维度统计用车情况：订单数、取消数、行程数、订单里程、行驶时长。

## 八、工作台

### 1. 查看上传文件

上传文件记录：来源（PC/Android）、文件名、上传人（工号/姓名）、标签、上传时间、下载链接，支持在线下载。

### 2. 用户中心

查看个人信息（姓名、工号、性别、电话），支持修改密码、更换头像。

## 九、公共能力

- **登录**：工号 + 密码 + 一次性口令（OTP）登录，支持中英文界面切换
- **表格**：右键表头自定义列隐藏/恢复、列表数据导出 Excel
- **页面**：返回顶部、跳到底部、多标签页切换
- **错误页**：404、401 页面
