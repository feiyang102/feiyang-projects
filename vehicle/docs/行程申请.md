# 行程申请（派车申请）功能说明

## 一、项目整体业务概述

本项目为 vivo 车辆服务的「派车申请」Web 前端，属于多页面应用，供员工在线填写并提交用车申请，申请单接入 BPM 审批流程流转。项目同时承载车辆与会议相关的若干独立页面：

| 页面 | 业务定位 | 说明 |
| --- | --- | --- |
| 派车申请（orderApplication） | 行程申请 | 核心页面，员工提交单程/往返用车申请 |
| 会议室预定（vMeeting） | 会议室管理 | 查询会议室、查看预定限制、提交预定申请 |
| 地图（map） | 地图应用 | 基于百度地图的独立页面 |
| 用户（user） | 用户信息 | 用户相关信息展示页面 |
| 应用日志（appLog） | 日志查看 | 应用运行日志查看页面 |
| 关闭（close） | 辅助页面 | 用于关闭窗口的辅助静态页 |

**集成与环境：**

- 支持 local / dev / test / prod 多套环境独立配置（接口地址、登录地址、BPM 地址）。
- 通过 UUC / BPM 单点登录（SSO）鉴权：进入页面无登录态时自动跳转统一登录，登录后自动获取当前用户的工号、姓名、手机号、部门、短号等信息用于表单回填。
- 申请单提交成功后跳转至 BPM 文档详情页查看流转状态。
- 附件上传存储于 BPM 文件服务。

## 二、行程申请页面功能描述

### 1. 页面布局与公共栏

- **顶部导航**：首页 / 公共行政 / 信息管理 / 派车申请后台 / 派车申请，展示当前页面所处模块层级。
- **操作按钮**：
  - 提交：校验表单并提交申请单，成功后跳转 BPM 详情页；
  - 关闭：关闭当前页面；
  - 选择时区：系统检测到用户电脑时区非东八区时额外显示，供用户选择"使用北京时间"或"使用本地时间"（提交时统一按北京时间处理）。
- **表单头（公文头）**：主题（可手动编辑，也可自动生成）、保密级别（公开 / 秘密 / 绝密，默认公开）、发布时间（自动取当前时间）、文件编号（自动生成）、拟制人（当前用户）、部门（当前用户部门）、当前状态（拟制）、当前处理人（当前用户）。

### 2. 行程申请正文（单程 / 往返）

- **行程需求**：单选「单程」或「往返」。选择往返时，正文下方展开「回程信息」区块，需填写回程的完整行程与乘车人信息。
- **出发地 / 目的地**：分别由「省市区」与「详细地址」两个输入项组成，点击后弹出百度地图弹窗选点，选点结果自动回填省市区、详细地址及坐标。
- **乘车人出发时间**：由「日期」+「时刻」两个控件组成，时刻按 15 分钟粒度选择。系统对可选时间做智能限制：
  - 当天 20:00 前可选择今天及之后日期，20:00 后最早只能选择明天；
  - 当天 8:00 前最早发车时间为 10:00，8:00 后最早发车时间为 2 小时后。
- **预计到达时间**：选择出发地、目的地后，系统自动估算行车距离与时长，并用「出发时间 + 预估时长」自动生成预计到达时间（只读，不可手改）；回程的「计划到达时间」可手动选择。
- **乘车人数**：数字输入，最小为 1，默认 1；修改后自动同步到回程。
- **乘车人信息**（姓名 / 工号 / 手机号 / 短号）：
  - 乘车人姓名：输入工号或姓名可远程搜索员工并选择，仅填一位；选人后自动带出该员工的工号、手机号、短号；
  - 乘车人工号：由选人自动带出（只读）；代发申请时务必填写乘车人工号；
  - 乘车人手机号：默认带出当前用户手机号，需为 11 位手机号（兼容 +86 前缀），修改后自动同步到回程；
  - 乘车人短号：非必填，默认带出当前用户短号。
- **用车原因**：必填，提示需填写具体原因，并附上出差单 / 商务接待单 / 工作联络单等单据链接。
- **其他要求**：非必填；如接机需求，需填写正确的航班号，否则无法派车。
- **是否测试用车**：按申请人身份条件显示（是 / 否）。
- **回程信息**（选择往返时显示）：包含回程出发地省市区及详细地址、回程目的地省市区及详细地址、乘车人出发时间、计划到达时间、乘车人数、乘车人姓名 / 工号 / 手机号 / 短号、其他要求。其中：
  - 若去程出发地 / 目的地已确定且回程对应地点未填，系统自动将回程出发地预填为去程目的地、回程目的地预填为去程出发地；
  - 乘车人数、手机号、短号随去程同步修改。

### 3. 地图选点交互

点击出发地 / 目的地任意输入项，弹出百度地图选点弹窗，支持以下操作：

- **关键词搜索**：输入内容后回车或点击搜索按钮进行地点检索，展示搜索结果列表，双击结果项可直接确认选点；
- **城市切换**：地图左上角提供城市列表切换；
- **定位**：地图右下角定位按钮，定位到当前位置；
- **地图点选**：直接点击地图任意位置选点，系统自动逆地址解析并展示该点周边定位点列表，可从列表中选择更精确的地点；
- **标记拖拽**：已选标记可拖拽微调位置，拖拽后自动重新解析地址；
- **常用地址**：地图左侧提供「常用地址」入口，展示后端下发的常用地址列表（含序号、名称、地址），点击即可选用；
- **确认 / 取消**：选点完成后点击「确定」回填表单。

### 4. 审批设置

- **审批记录**：展示审批节点「拟制（申请人）」与「主管或经理审核」。
  - 主管或经理审核：默认自动带出乘车人的直接上级；若申请人为总经理及以上人员，则无需上级审核（默认本人）；审核人可手动改选，且审核人与乘车人不能为同一人。
- **抄送**：可远程搜索员工并多选抄送人员，随申请单一起提交。

### 5. 附件

- 支持上传附件，最多 6 个；上传成功后显示文件名、大小、上传人及时间；
- 支持在线查看（预览图片）与删除附件；删除时需二次确认。

### 6. 智能逻辑与规则

- **主题自动生成**：当乘车人、出发日期、出发地、目的地齐备时，自动生成主题，格式为「乘车人姓名 + 日期 +（往返）行程 + 出发城市 -> 到达城市」，生成后可手动修改（最长 200 字）。
- **单程 / 往返联动**：确定去程出发地或目的地后，若回程对应地点尚未填写，自动预填反向地点。
- **路程估算与距离校验**：选点完成后自动调用路程估算，计算距离与行车时长；提交时校验单程及回程的出发地-目的地距离均不超过 300KM，超出则拦截并提示。
- **必填校验**：出发地、目的地、出发时间、到达时间、乘车人数、乘车人姓名、手机号、用车原因、主管或经理审核均不能为空；往返行程还需校验回程全部必填项。
- **手机号格式校验**：需为 11 位手机号，兼容 +86 / (+86) 前缀写法。
- **审核人与乘车人互斥校验**：审核人与乘车人不能相同（总经理及以上人员除外）。
- **防重复提交**：提交过程中禁止重复点击，避免生成重复申请单。
- **时区处理**：非东八区时区时提示选择使用北京时间或本地时间，提交时统一转换为北京时间。
- **登录集成**：无登录态自动跳转 SSO 登录，登录后自动填充拟制人、部门、乘车人手机号等个人信息。

| 出发地省市区 | 是 | 地图选点 | 点击弹出百度地图选择省市区 |

| 乘车人短号 | 否 | 文本 | 默认当前用户短号；修改后同步回程 |

| 其他要求 | 否 | 文本 | 如接机需填写正确航班号 |
| 是否测试用车 | 条件显示 | 单选 | 按申请人身份条件显示，是 / 否 |
